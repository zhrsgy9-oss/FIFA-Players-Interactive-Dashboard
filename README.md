# FIFA Players — Interactive Dashboard

An interactive football analytics dashboard built with **Python and Plotly**, designed to explore FIFA player attributes, compare player profiles, and discover patterns across nationalities, ages, and playing positions.

## Project Overview

This project presents an interactive exploration of FIFA player data through a collection of visualizations. The dashboard brings multiple perspectives together in one interface, allowing users to explore player characteristics and compare different aspects of performance.

The dashboard uses a dark **Neon-Luxury** visual theme, with interactive charts and a customizable layout.

## Visualizations

The dashboard includes several visual analyses, such as:

- **Player Attribute Radar:** Exploring player attribute profiles.
- **Goalkeeper Analysis:** Examining goalkeeper-specific attributes.
- **Player Attributes by Position:** Comparing attributes across position groups.
- **Age and Performance Analysis:** Exploring the relationship between age, overall rating, potential, and other attributes.
- **Nationality Distribution:** Visualizing the geographical distribution of players.
- **Top Nationalities:** Comparing the most represented nationalities.
- **Potential vs. Overall Rating:** Investigating the relationship between current overall rating and potential.
- **Attribute Relationships:** Exploring selected technical and physical attributes.
